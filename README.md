# 🚀 CESI to Dublin 2026

> Site vitrine pour le projet étudiant CESI Nancy - Participation au Dublin Tech Summit 2026

## 📋 Description

Ce site web présente le projet étudiant de l'équipe CESI Nancy qui souhaite participer au **Dublin Tech Summit 2026**. Il s'agit d'un site vitrine à but non lucratif permettant de présenter l'équipe, le projet, et de collecter des fonds pour financer ce voyage d'étude.

## 🎯 Objectifs du Projet

- **Découvrir l'écosystème tech irlandais** lors du Dublin Tech Summit 2026
- **Assister aux conférences** les plus innovantes du secteur
- **Rencontrer des professionnels** du domaine technologique
- **Étendre le réseau professionnel** international
- **Découvrir les dernières tendances** technologiques

## 🚀 Installation et Lancement

### Prérequis
- **Node.js** (version 16 ou supérieure)
- **npm** ou **yarn**

### Installation
```bash
# Cloner le projet
git clone [URL_DU_REPO]
cd dublin2026

# Installer les dépendances
npm install
```

### Développement
```bash
# Lancer le serveur de développement
npm run dev

# Le site sera accessible sur http://localhost:5173
```

### Production
```bash
# Construire pour la production
npm run build

# Prévisualiser la build de production
npm run preview
```

## 🎨 Design et UX

- **Palette de couleurs** : Bleu CESI (#007BFF) avec dégradés

Le site est entièrement responsive et s'adapte à tous les écrans :
- **Mobile** : < 768px
- **Tablette** : 768px - 1024px  
- **Desktop** : > 1024px
